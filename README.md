# IPTV playlist
 
Builds a grouped playlist (EX-YU, International, News, Movies, Sports, Kids...)
from the free iptv-org channel lists. GitHub Actions rebuilds it every day.
 
Playlist link for the TV app:
https://raw.githubusercontent.com/YOUR-USERNAME/my-iptv/main/playlist.m3u
 
To change folders, edit the GROUPS list at the top of build_playlist.py,
then run the workflow again (Actions -> Update playlist -> Run workflow).
